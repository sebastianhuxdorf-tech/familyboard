FamilyBoard – Tablet-Testversion (Android 8.1 / Chrome 101)
==========================================================
Diese Version basiert auf FamilyBoard_Vollbild_AutoGoogle.zip.
Änderungen:
- Automatische Google-Anmeldung beim Seitenstart deaktiviert.
- Manuelle Google-Anmeldung und Eingabeprüfung der OAuth-Client-ID.
- Sonstiges Dashboard-Layout, Kalender, Tasks und Profile unverändert.

WICHTIG: Dies ist ein Diagnosetest, keine garantierte Lösung für Fehler 401 invalid_client.
Bei weiterhin auftretendem Fehler liegt das Problem nicht an der automatischen Anmeldung.
Auf beiden Tablets kann dieselbe Datei verwendet werden. Vorhandene lokale Einstellungen
bleiben bei gleicher GitHub-Pages-Adresse erhalten.

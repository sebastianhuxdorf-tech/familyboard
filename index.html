Google-Verbindung

Die Google-Anmeldung ist bereits eingebaut. Trage unten deine OAuth-Client-ID aus Google Cloud ein und klicke auf „Google-Konto verbinden“. Die Client-ID ist kein Passwort; Zugriffstokens werden nicht dauerhaft gespeichert.

Nicht verbunden
Auf dem Familien-Tablet: Erst dein Google-Konto verbinden, dann den Kalender deiner Freundin über Google Kalender für dein Konto freigeben und hier beide Kalender auswählen. Auf Tylers Tablet sein Google-Konto verbinden. Die Konten sind nicht miteinander vermischt. Wichtig: Google Calendar API und Google Tasks API im Cloud-Projekt aktivieren. Zum Bearbeiten der Aufgaben benötigt die App den Berechtigungsbereich https://www.googleapis.com/auth/tasks (nicht nur tasks.readonly).
